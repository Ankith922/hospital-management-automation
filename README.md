This project is a cloud-based Hospital Management System built using Google tools to automate and simplify hospital operations. It efficiently manages patient data, performs analysis, and generates medication receipts.

🚀 Features
📝 Patient data collection using Google Forms
📊 Automatic data storage in Google Sheets
📋 Patient record management and tracking
📈 Data analysis using formulas and functions
💊 Medication billing and receipt generation
📤 Receipt sharing with patients
☁️ Cloud-based and real-time access

🛠️ Technologies Used
Google Forms
Google Sheets
Google Apps Script (for automation)

⚙️ Working
Patients fill in their details through Google Forms.
The data is automatically stored in Google Sheets.
The system processes and analyzes patient information.
Treatment and medication details are recorded.
A receipt for medications is generated automatically.
The receipt is shared with the patient.

🎯 Objective
To develop a simple, cost-effective, and cloud-based hospital management system that reduces manual work and improves efficiency.

📌 Advantages
Easy to use and maintain
No installation required
Real-time updates
Reduces manual errors
Suitable for small clinics and hospitals
